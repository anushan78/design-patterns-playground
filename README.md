# C# Design Patterns Playground

A clean, real-world focused collection of **GoF design patterns implemented in C#**.

## Goals
- Simple, minimal examples
- Real-world use cases (not academic demos)
- Interview-ready explanations
- Modern C# style (async, immutability where possible)

## Implemented Patterns

### Creational
- Factory Method – Notification sender creation (Email, SMS)

### Behavioral
- Strategy – Notification channel selection

## Structure
- src/
- Patterns.Creational/
- Patterns.Behavioral/
- tests/

dotnet run --project src/Patterns.Behavioral
